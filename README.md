# cp932-dict-gen

Windows 標準の Shift-JIS（**CP932 / Windows-31J**）に存在しない中国語漢字（繁体字 Big5・簡体字など）を、**古の Win32 アプリ（MangaMeeya 等）でも 100% 読み込める「日本の CP932 漢字（1対1異体字）」または「半角カナ＋CP932漢字による偏旁分解（疑似漢字）」** へ自動変換し、変換辞書（CSV対応表）を生成する CLI ツールです。

ファイル名クレンジングツール **[name2win](https://github.com/emmmanime/name2win)** および Discord 画像・添付ファイル保存スクリプト **[discord-oneclick](https://github.com/emmmanime/discord-oneclick)** に組み込むための変換テーブル作成・検証エンジンとして設計されています。

> [!IMPORTANT]
> **【本ツールの目的と文字変換方針に関するお断り】**
> 本ツールの目的は、あくまでも **「古の Win32 アプリ（非 Unicode アプリ）がエラーを起こさずにファイルをオープンできること」** および **「すべてが『■』等に潰れてしまうのを防ぎ、人間が一目で元の文字のニュアンス（見た目・雰囲気）を判別できるように整えること」** にあります。
> 半角カナや代替パーツを用いた文字変換のアプローチは、本来の漢字学・言語学的な見地からは懸け離れた便宜上の表現であり、学術的・言語学的な正しさを追求するものではありません。そのため、言語学的な観点からのご指摘や議論にはお応えいたしかねますので、あらかじめご了承ください。

## 💡 背景とコンセプト

### 1. 繁体字（Big5）と CP932 の収録ギャップ
台湾・香港の繁体字標準文字セットである **Big5（CP950：全 13,051 字）** と **Windows CP932（全 6,682 字）** を比較すると、以下のギャップが存在します。

| Big5 区分 | 収録漢字数 | CP932 に存在する | **CP932 に存在しない（固有字）** | 備考 |
| :--- | ---: | ---: | ---: | :--- |
| **第1水準（常用漢字）** | 5,401 字 | 4,469 字 (82.7%) | **932 字 (17.3%)** | 日常語・作品タイトル等の **99.9%以上** をカバー |
| **第2水準（次常用漢字）** | 7,650 字 | 1,056 字 (13.8%) | **6,594 字 (86.2%)** | 古語・特殊な固有名詞・異体字 |
| **合計（Big5 全体）** | **13,051 字** | **5,525 字** | **7,526 字** | |

### 2. なぜ「半角カナ ＋ 偏旁分解（疑似漢字）」なのか？
Unicode には「にんべん (`亻` `U+4EBB`)」「さんずい (`氵` `U+6C35`)」「てへん (`扌` `U+624C`)」「しめすへん (`礻` `U+793B`)」などの部首単体文字が存在しますが、**これらの部首単体文字はすべて CP932 非対応** であり、古の Win32 アプリでは `?` に文字化けしてファイルを開けなくなります。

一方で、**CP932 の半角カタカナ（`0xA1`〜`0xDF`）は全角1文字の半分の横幅で描画される** ため、左側の「偏（へん）」や右側の「旁（つくり）」として CP932 漢字と組み合わせることで、古の日本のテキスト文化（Shift-JIS アスキーアート／疑似漢字表現）と同様に、視覚的・直感的に元の文字が判別できる代替表記を作り出すことができます。

* **変換例**:
  * `妳` (`U+59B3`) ➔ **`女尓`** （女偏 ＋ CP932第2水準の『尓』）
  * `你` (`U+4F60`) ➔ **`ｲ尓`** （半角カナ『ｲ』＋『尓』）
  * `嗎` (`U+55CE`) ➔ **`ﾛ馬`** （半角カナ『ﾛ』＋『馬』）
  * `扔` (`U+6254`) ➔ **`ｷ乃`** （半角カナ『ｷ』［てへん］＋『乃』）
  * `裡` (`U+88E1`) ➔ **`ﾈ里`** （半角カナ『ﾈ』［ころもへん］＋『里』）
  * `划` (`U+5212`) ➔ **`戈ﾘ`** （『戈』＋半角カナ『ﾘ』［りっとう］）
  * `說` (`U+8AAA`) ➔ **`説`** （日本の JIS 第1水準漢字へ 1対1 置換）

## ⚙️ 5段階の自動変換パイプライン仕様

本ツールはオープンな異体字データベース（OpenCC / CJKVI）と漢字構造記述データベース（CHISE IDS：約8.8万字）を組み合わせ、以下の優先順位で変換候補を自動生成します。

1. **`[Phase 1]` プリセット定義（手動・頻出語優先ルール）**
   * 最頻出の口語字（`妳`➔`女尓`、`你`➔`ｲ尓`、`她`➔`女也`、`嗎`➔`ﾛ馬`、`呢`➔`ﾛ尼`、`吧`➔`ﾛ巴` など）および特殊な非CP932構成パーツの代替定義を最優先で適用します。
2. **`[Phase 2]` 日本新字体・正字への厳密な 1対1 置換**
   * 常用漢字・人名用漢字・表外漢字字体表・旧字体対応表（`JPShinjitaiCharacters` / `joyo` / `jinmei` / `hyogai` / `jp-old-style` 等）に基づき、日本の CP932 漢字に 1対1 で対応する字を1文字で置換します。
   * 例：`說`➔`説`、`步`➔`歩`、`每`➔`毎`、`吳`➔`呉`、`內`➔`内`、`溫`➔`温`、`黃`➔`黄`、`幫`➔`幇`、`姊`➔`姉`
   * ※ 漢語大字典（`hydzd`）等の「古代の通仮字・別字置換」をここで適用すると、視覚的に分かりやすい偏旁分解（例：`圾`➔`土及`、`囝`➔`囗子`）が別字（`岌` や `月`）に潰れてしまうため、Phase 2 では厳密な正字・新字体のみを対象としています。
3. **`[Phase 3]` IDS（漢字構成記述文字列）構造正規化による 1対1 同定**
   * 対象文字の IDS（例：`説` の簡体字 `说` ＝ `⿰讠兑`）の構成要素を CP932 標準字形（`⿰言兌`）に正規化し、既存の CP932 漢字 1 文字と構造が完全一致する場合はその漢字（`説`）を割り当てます。
4. **`[Phase 4]` IDS 偏旁分解 ＋ 半角カナ・CP932 部首合成**
   * 1文字の CP932 漢字に置換できない文字について、IDS の木構造（左右 `⿰`、上下 `⿱`、繞 `⿺`、垂 `⿸`、構 `⿴` 等）を再帰的に解析し、部首（半角カナや CP932 第2水準部首）と旁（構成漢字）の組み合わせに展開します。
5. **`[Phase 5]` 広義異体字・古典字フォールバック**
   * Phase 4 でも分解できなかった稀少字・特殊構造字に対してのみ、台湾教育部異体字字典（`twedu`）や漢語大字典（`hydzd`）等の広義異体字辞書から CP932 収録字を補完します。

| **さんずい**（偏） | `氵` (`U+6C35`) / `⺡` | **`ｼ`** (`0xBC`) | 半角カナの「シ」 | `汙`➔`ｼ于`, `汍`➔`ｼ丸`, `沅`➔`ｼ元`, `汴`➔`ｼ卞` |
| **てへん**（偏） | `扌` (`U+624C`) / `⺘` | **`ｷ`** (`0xB7`) | 半角カナの「キ」（古のShift-JIS慣用表現） | `扔`➔`ｷ乃`, `扒`➔`ｷ八`, `扭`➔`ｷ丑`, `扳`➔`ｷ反` |
| **しめす・ころも**（偏） | `礻` (`U+793B`) / `衤` (`U+8864`) | **`ﾈ`** (`0xC8`) | 半角カナの「ネ」で両者をシンプルに表現 | `祂`➔`ﾈ也`, `裡`➔`ﾈ里`, ``➔`ﾈ浸` |

| **りっとう**（旁） | `刂` (`U+5202`) / `⺉` | **`ﾘ`** (`0xD8`) | 右旁の「刂」を半角カナ「リ」で再現 | `划`➔`戈ﾘ`, `刖`➔`月ﾘ`, `刨`➔`包ﾘ`, `剁`➔`朶ﾘ` |

| **うかんむり**（冠） | `宀` (`U+5B80`) | **`宀`** (`9B-7E`) | CP932 JIS第2水準の部首文字をそのまま使用 | `宀`＋下部の構成字 |
| **くさかんむり**（冠） | `艹` (`U+8279`) / `⺾` | **`艸`** (`E4-87`) | CP932 JIS第2水準の「艸（くさ）」を使用 | `芾`➔`艸一巾` |

| **こざと・おおざと** | `阝` (`U+961D`) / `⻖` / `⻏` | **`卩`** (`99-C5`) | CP932 JIS第2水準の「卩（ふしづくり）」 | `邢`➔`開卩`, `鄞`➔`菫卩` |

## 🚀 ビルド方法と使い方

Windows 10 / 11 に標準搭載されている .NET Framework の C# コンパイラ（`csc.exe`）だけでビルドできます（追加の SDK インストールは不要です）。

### ビルド手順

```powershell
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe /nologo /out:cp932-dict-gen.exe cp932-dict-gen.cs
```

### コマンドラインオプション

```text
使用法: cp932-dict-gen.exe [-v|--verbose] [-a|--all] [-t <文字列>] [-o <出力CSVパス>]
  -v, --verbose : 冗長モード（各フェーズの進行状況と1文字ずつの変換根拠ログを出力）
  -a, --all     : Big5第2水準（次常用6,594字）も含めた全7,526字を対象にする（既定は第1水準932字）
  -t, --test    : 指定した文字列を本ジェネレーターの辞書で変換シミュレーションする
  -o, --out     : 出力先CSVファイルパスを指定
```

## 📄 出力 CSV ファイル仕様

生成される CSV ファイルは **UTF-8（BOM付き）** で出力されるため、Microsoft Excel でダブルクリックして直接文字化けせずに開くことができます。

| 列名 | 内容 |
| :--- | :--- |
| **`Big5水準`** | `第1水準(常用)`（932字）または `第2水準(次常用)`（6,594字） |
| **`変換対象`** | CP932 に存在しない元の繁体字 1 文字 |
| **`Unicode`** | Unicode コードポイント（例：`U+59B3`） |
| **`Big5コード`** | Big5（CP950）16進コード（例：`A670`） |
| **`変換先文字列`** | 自動生成された CP932 互換の変換先文字列（すべての文字が CP932 検証済み） |
| **`生成フェーズ`** | どのフェーズで解決されたか（`1:プリセット` 〜 `5:広義異体字/同義字`） |
| **`IDS構造`** | CHISE IDS における漢字構成記述文字列（例：`⿰女爾`） |
| **`メモ`** | 変換根拠や参照した辞書・分解式の詳細 |
